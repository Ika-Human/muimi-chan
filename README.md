# muimi-chan

「むいみちゃん」を固定キャラクターとして定義するためではなく、作品群の中で繰り返し発生している現象、身体性、知覚、発話、媒体変換を観察・記録するためのリポジトリです。

## 現在の位置づけ

むいみちゃんは、少なくとも現時点では「設定」より「現象」に近いものとして扱います。

中心仮説は次の通りです。

> 世界と別々でいたい身体と、世界から別々ではいられない身体のあいだに生じ続けるもの。

ただし、この文章自体も定義ではありません。観測のための一時的な足場です。

現在有効な観測語:

- **アトラクタ** — 同一の形・語彙・軌道を保存しないのに、作品が繰り返し近傍へ引き寄せられるという観測上の比喩。
- **不安定な場** — 理解可能性が生まれては死ぬ。安定／不安定の周期は固定されず、長く安定することも即座に崩れることもある。
- **終わらない代謝** — 外部を完全に自己へ同化できず、排除もできず、身体と世界がお互いを消化し続ける。
- **原初のさざなみ** — 乾燥と湿潤の間のように、形が生まれうる条件が局所的に成立し続けるという比喩。

これらはいずれも「正体の定義」ではありません。

## Repository

- `Docs/MUIMI_RESEARCH.md` — 現在の統合分析。正本。
- `Docs/SOURCES.md` — 一次作品・公開資料・理論参照。
- `AGENTS.md` — AI / Codex がこのリポジトリを扱う際の制約。

## 重要な非要件

このリポジトリでは、以下を目的としません。

- 身長、髪型、性格、語尾などの固定キャラクター表を完成させること
- 「むいみちゃん風」を再現する生成アルゴリズムを作ること
- 『むいみちゃん　簒』の「簒」に意味論を過剰に背負わせること
- 毎回同じ崩壊パターンを再現すること
- ランダムさそのものを、むいみちゃんと同一視すること

『簒』は現時点では三番目を指す便宜的な記号です。
